Single image display

The core lightbox behavior and how to attach captions or copyright notices to a single image.

Basic usage

A plain image with no caption or grouping.

HTML

<a href="large-image.webp"
   class="lightbox">
  <img src="thumbnail-image.webp" alt="...">
</a>

Captions via attribute

Using data-caption directly on the link.

HTML

<a href="large-image.webp"
   class="lightbox"
   data-caption="A day trip to Leiden on our vacation in the Netherlands.">
  <img src="thumbnail-image.webp" alt="...">
</a>

Captions by ID reference

Using data-caption-id to reference an existing <figcaption>.

HTML

<figure>
  <a href="large-image.webp"
     class="lightbox"
     data-caption-id="caption-1">
    <img src="thumbnail-image.webp" alt="...">
  </a>
  <figcaption id="caption-1">
    Picturesque house facades in Leiden, a city in South Holland, Netherlands.
  </figcaption>
</figure>

Copyright via attribute

Using data-copyright alongside a caption.

HTML

<a href="large-image.webp"
   class="lightbox"
   data-copyright="© 2026 Photography Studio">
  <img src="thumbnail-image.webp" alt="...">
</a>

Copyright by ID reference

Using data-copyright-id to reference an external element.

© 2026 Street Photography Collection

HTML

<a href="large-image.webp"
   class="lightbox"
   data-copyright-id="copyright-1">
  <img src="thumbnail-image.webp" alt="...">
</a>

<div id="copyright-1" hidden>© 2026 Street Photography Collection</div>

Responsive srcset

Using data-srcset to serve the right resolution to the lightbox.

HTML

<a href="large-image.webp"
   class="lightbox"
   data-srcset="large-image-1200.webp 1200w, large-image-1000.webp 1000w, large-image-700.webp 700w, large-image-500.webp 500w">
  <img src="thumbnail-image.webp" alt="...">
</a>

Alternative triggers

Parvus doesn't require a thumbnail image — any link or button can open the lightbox.

Text links

Opening images from plain text links, no thumbnail involved.

View Photo 1 View Photo 2 View Photo 3

HTML

<a href="large-image.webp"
   class="lightbox">
  View Photo 1
</a>

// ...

Button elements

Using a <button> with data-target instead of a link.

HTML

<button class="lightbox-button"
        data-target="large-image.webp">
  Open Image via Button
</button>

Grouping & galleries

Ways to tell Parvus that several images belong together and should be navigable as a set.

Grouping with data-group

Images explicitly grouped together using data-group="Netherlands".

HTML

<a href="large-image.webp"
   class="lightbox"
   data-group="Netherlands">
  <img src="thumbnail-image.webp" alt="...">
</a>

// ...

Grouping with gallerySelector

Images grouped by their shared parent container.

HTML

<div class="gallery-xy">
  <a href="large-image.webp"
     class="lightbox">
    <img src="thumbnail-image.webp" alt="...">
  </a>

  // ...
</div>

JS

new Parvus({
  gallerySelector: '.gallery-xy'
})

Mixed groups

Different groups living side by side on the same page.

HTML

<a href="large-image.webp"
   class="lightbox"
   data-group="groupA">
  <img src="thumbnail-image.webp" alt="...">
</a>
<a href="large-image.webp"
   class="lightbox"
   data-group="groupB">
  <img src="thumbnail-image.webp" alt="...">
</a>
<a href="large-image.webp"
   class="lightbox"
   data-group="groupA">
  <img src="thumbnail-image.webp" alt="...">
</a>

Advanced configuration

Scoping instances to a container, localizing the UI, and extending Parvus with plugins.

Scoped instances via root

Two independent instances share the same selector class but are each scoped to their own container via the root option, so they don't pick up each other's triggers.

Container A (root as element reference)

HTML

<div id="scope-a">
  <a href="large-image.webp"
     class="lightbox">
    <img src="thumbnail-image.webp" alt="...">
  </a>
</div>

JS

new Parvus({
  root: document.querySelector('#scope-a')
})

Container B (root as selector string)

HTML

<div id="scope-b">
  <a href="large-image.webp"
     class="lightbox">
    <img src="thumbnail-image.webp" alt="...">
  </a>
</div>

JS

new Parvus({
  root: '#scope-b'
})

Localization

Using an alternate language file. This example uses German (l10n: de).

HTML

<a href="large-image.webp"
   class="lightbox">
  <img src="thumbnail-image.webp" alt="...">
</a>

JS

import de from '../src/l10n/de.js'

new Parvus({
  l10n: de
})
